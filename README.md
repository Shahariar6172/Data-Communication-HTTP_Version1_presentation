## Key Points
 
- HTTP is a text-based, stateless, request–response protocol over TCP (port 80).
- Versions: HTTP/0.9 (1991), HTTP/1.0 (1996, RFC 1945), HTTP/1.1 (1997, RFC 2068; now RFC 9110/9112).
- HTTP/1.1 added persistent connections, the Host header, and better caching.
- Its limits (head-of-line blocking, repeated headers, no encryption) led to HTTP/2, HTTP/3 and HTTPS.
